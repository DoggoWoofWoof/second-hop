          Data and methods

          First search

          Dense and sparse retrievers order the passages by meaning and words. Reciprocal rank fusion combines those orders.

          Pool replay

          Each selected search hit contributes its direct neighbours from the enabled link types. Duplicate passages count once. The opening graph contains the neighbours of the first 25, 100, or 200 search hits. Shrinking keeps the active seeds and the passages they can reach. Link density counts each pair once. Large views draw fewer background lines; all enabled links still affect the layout and density.

          Ranking replay

          The demo adds a bonus to each neighbour based on its best connected search hit. The bonus equals that hit’s fused score times the number of enabled link types on the connection, divided by four, times the chosen boost. The saved MLP and GNN runs used a fixed shortlist and seed 0.
